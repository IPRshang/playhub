🚀 GitHub Pages 部署教程

三步完成，把你的小游戏网站发布到互联网

1

在 CodeBuddy 中授权 GitHub

点击 CodeBuddy 左下角的 ⚙️ 设置 图标：

CodeBuddy
⚙️ 设置
🔌 连接器
🎨 主题
⌨️ 快捷键

🔌 连接器管理

🐙 GitHub 未连接

👆 点击右侧绿色 "连接" 按钮，按提示完成 OAuth 授权

⬇️
2

在 GitHub 上创建仓库

打开 github.com，登录后点击右上角 + → New repository：

🐙 GitHub

Create a new repository

🔓 Public（公开仓库）
⚠️ 不要勾选 "Add a README file"（我们已经有了）

创建后你会看到一个页面显示：
…or push an existing repository from the command line

⬇️
3

回到 CodeBuddy，告诉我「已授权」

完成上面两步后，回到这里告诉我，我会执行：

  1. 把代码推送到你的 GitHub 仓库
  2. 在仓库设置中开启 GitHub Pages
  3. 等待 Actions 自动部署完成（约 30 秒）

🎉 你的网站地址将是：

https://你的用户名.github.io/playhub/

之后每次你推送新代码，GitHub Actions 会自动重新部署，无需手动操作 ✨
